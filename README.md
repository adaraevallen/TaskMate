# TaskMate — Personal Study Planner

TaskMate is a web-based study planner designed to help students organize their tasks, manage their study schedules, and stay focused while learning.

With a simple and practical interface, TaskMate helps students manage their academic activities more effectively in one place.

## 🌐 Live Demo

Try TaskMate here: [adaraevallen.pythonanywhere.com](https://adaraevallen.pythonanywhere.com/)

## ✨ Features

- **Task Management** — Add and manage study tasks.
- **Focus Timer** — Support focused study sessions and better time management.
- **Calendar** — Organize and view study schedules.
- **Simple Interface** — Easy-to-use navigation for daily academic activities.

## 🛠️ Built With

- Python
- Flask
- HTML
- CSS
- JavaScript
- JSON for data storage

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/adaraevallen/TaskMate.git
cd TaskMate
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it:

**Windows**
```bash
venv\Scripts\activate
```

**macOS / Linux**
```bash
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```
